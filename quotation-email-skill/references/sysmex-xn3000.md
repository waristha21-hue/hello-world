# Sysmex CBC XN-3000 — Reference สำหรับ Quotation Email

## ผลิตภัณฑ์
- XN-3000: Automated Hematology Analyzer (CBC + Differential)

## จุดเด่นหลัก
- CBC พร้อม 5-part differential อัตโนมัติ
- throughput สูง รองรับ high volume lab
- IPU (Intelligent Platelet count) แม่นยำ
- Body fluid analysis mode
- เชื่อมต่อ LIS / middleware ได้
- Fluorescence flow cytometry technology

## จุดเด่นสำหรับ แพทย์/หัวหน้าแล็บ
- ผลแม่นยำ ลด smear review rate
- Reticulocyte และ immature cell flagging
- Extended IPF (Immature Platelet Fraction) สำหรับ clinical decision
- ลด TAT อย่างมีนัยสำคัญ

## จุดเด่นสำหรับ จัดซื้อ
- ลดค่าใช้จ่าย reagent ระยะยาว
- ลด FTE ที่ต้องทำ manual diff
- รับประกันและบริการหลังการขายครบ
- มีทีม application specialist สนับสนุน
